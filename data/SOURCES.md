# Data sources

| File | What it is | Origin |
|---|---|---|
| `top_500_companies.csv` | ~520 top US tech employers (one `company` column) | Copied from [job-pipeline](https://github.com/atishay-kasliwal/job-pipeline/blob/main/data/top_500_companies.csv) |
| `h1b_2026.csv` | ~1,400 companies that sponsored H-1B visas (one `company` column) | Copied from [job-pipeline](https://github.com/atishay-kasliwal/job-pipeline/blob/main/data/h1b_2026.csv) |
| `companies.json` | Company → job-board map (`name`, `ats`, `token`) | Generated by `scripts/discover-companies.ts` from `top_500_companies.csv` |
