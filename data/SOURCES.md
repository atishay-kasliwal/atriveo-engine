# Data sources

## Bundled data

| File | What it is | Origin |
|---|---|---|
| `top_500_companies.csv` | ~520 top US tech employers (one `company` column) | Copied from [job-pipeline](https://github.com/atishay-kasliwal/job-pipeline/blob/main/data/top_500_companies.csv) |
| `h1b_2026.csv` | ~1,400 companies that sponsored H-1B visas (one `company` column) | Copied from [job-pipeline](https://github.com/atishay-kasliwal/job-pipeline/blob/main/data/h1b_2026.csv) |
| `companies.json` | Company → job board (`name`, `ats`, `token`) | Generated by `bun scripts/discover-companies.ts` from `top_500_companies.csv` |

`companies.json` is a heuristic match: board tokens are guessed from company
names. Greenhouse boards are kept only when the name the board reports matches;
Lever and Ashby boards report no name, so at least a third of their postings
must mention the company. Companies on other systems (Workday, iCIMS, their own
sites) aren't covered. Add any board with `atriveo companies add <careers-url>`.

## Job sources

Every request sends `User-Agent: atriveo-engine/<version> (+https://github.com/atishay-kasliwal/atriveo-engine)`.
The engine does not scrape LinkedIn, Indeed, Glassdoor, or any site's HTML.

| Source | Endpoint | Terms we follow |
|---|---|---|
| Greenhouse | [Job Board API](https://developers.greenhouse.io/job-board.html) `boards-api.greenhouse.io/v1/boards/{token}/jobs` | Public, keyless, meant for listing a company's jobs. Descriptions are fetched per job, only for postings that pass the title and location filters, and cached. |
| Lever | [Postings API](https://github.com/lever/postings-api) `api.lever.co/v0/postings/{company}?mode=json` | Public, keyless. |
| Ashby | [Public job posting API](https://developers.ashbyhq.com/docs/public-job-posting-api) `api.ashbyhq.com/posting-api/job-board/{org}` | Public, keyless. Unlisted postings are skipped. |
| Remotive | [Remote jobs API](https://remotive.com/api-documentation) `remotive.com/api/remote-jobs?category=software-dev` | Link back to the Remotive URL and name Remotive as the source (every posting keeps its Remotive link and `attribution: "Remotive"`); don't pass the jobs to other job sites; call at most four times a day (the response is cached for six hours). Remotive shows jobs 24 hours after they're posted. |
| Arbeitnow | [Job board API](https://www.arbeitnow.com/blog/job-board-api) `arbeitnow.com/api/job-board-api` | Free; don't abuse it and link back to Arbeitnow. One page per run, cached for 55 minutes; postings keep their Arbeitnow link and `attribution: "Arbeitnow"`. Mostly European jobs. |

Board fetches run six at a time per source, time out after 30 seconds, and
retry 429 and 5xx responses up to three times with exponential backoff,
honoring `Retry-After`.

## Fixtures

Tests never touch the network. `test/fixtures/*.json` are hand-written
responses with fictional companies; `test/fixtures/shapes/*.json` record the
field names and types (no values) of each live API, made by
`bun scripts/record-shapes.ts`. `test/contract.test.ts` checks that every
fixture field exists in the live shape with the same type, and that every
field the parsers read is still there. When an API changes, re-record the
shapes and the contract tests show what moved.
